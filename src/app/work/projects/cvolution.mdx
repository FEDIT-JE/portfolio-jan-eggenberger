## Overview

Led the development of a tailored web application for CVolution GmbH, a Swiss company specializing in professional application services and career development. The project aimed to enhance the user experience across their digital platforms by implementing this web application.​

## Key Features

- **Résumé Creation**: Presentation of services for analyzing career paths and crafting personalized professional résumés.​
- **Video Application**: Integration of features to assist in creating personal concepts and scripts for video applications.​
- **Career Counseling**: Provision of information to analyze strengths, interests, and goals for career development.​

## Technologies Used

- **Next.js**: For fast, server-rendered React applications.
- **Figma**: For creating and managing design assets and prototypes.
- **Styled-Components**: For styling React components with a modular, themable approach.
